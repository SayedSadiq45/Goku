# GOKU

> A kinetic visual identity for ideas that refuse to sit still.

**GOKU** is an interactive, full-screen visual experience by **Sayed Sadiq**. Move across the page to reveal a second layer of the artwork through a responsive cursor trail, blending motion, image treatment, and a sharp neon interface.

## Live Website

Experience it here: [goku-wheat.vercel.app](https://goku-wheat.vercel.app/)

## Highlights

- Interactive canvas reveal controlled by mouse or touch movement
- Responsive full-screen presentation for desktop and mobile
- Layered Goku artwork with a smooth motion trail
- Direct links to Sayed Sadiq's [GitHub](https://github.com/SayedSadiq45) and [LinkedIn](https://www.linkedin.com/in/sayed-sadiq45/)
- Zero-build static site that runs directly in a browser

## Run Locally

Clone the repository and open `index.html` in a browser. Keep `1.jpg` and `2.jpg` in the same directory as the HTML file so the canvas layers can load correctly.

For a local server, run:

```bash
npx serve .
```

Then open the local URL shown in your terminal.
